# my-finance-harness

Хаб личных финансов: отчёты, анализ и управление через Claude по готовым скиллам.
Общение, документация и сообщения коммитов — на русском.

## Проекты

| Папка | Назначение |
|---|---|
| `freedom-broker/` | Брокерский счёт Freedom Broker: портфель, правила, наставники, консультант (скиллы `fb-portfolio`, `fb-invest`, `fb-advisor`, только чтение) |
| `zen-money-accounting/` | Учёт повседневных доходов/расходов: разбор банковских выписок → операции в Дзен-мани через коннектор |

У каждого проекта свой `CLAUDE.md` — читай его перед работой в проекте.

## Скиллы

Исходники скиллов лежат в `<проект>/skills/<скилл>/`. В `~/.claude/skills/` — только симлинки на них:

```bash
ln -sfn "$PWD/<проект>/skills/<скилл>" ~/.claude/skills/<скилл>
```

Префиксы: `fb-*` — freedom-broker, `zm-*` — zen-money-accounting.
Сторонние скиллы — в `<проект>/skills/vendor/<автор>/<скилл>/` с `VENDOR.md` (источник, коммит, лицензия, локальные правки),
симлинк под исходным именем.

## Жёсткие правила

1. **Исходные документы не хранятся.** PDF/XLSX/CSV-выписки кладутся только во временный `inbox/`, после обработки удаляются. В git их нет (`.gitignore` + `.githooks/pre-commit`).
2. **Хранится только история решений** — журналы `journal/*.jsonl` (только дописывать) и выученные правила `rules/`.
3. **Никаких персональных идентификаторов**: номера карт и счетов — маской `*1234`, ИИН, логины, API-ключи, токены — никогда.
4. Репозиторий — только локальный или приватный.

## Коммиты — Conventional Commits

Формат заголовка: `<тип>(<scope>)!: <описание>` — описание на русском, с маленькой буквы, в повелительном/
описательном виде, без точки, заголовок ≤ 72 символов. Подробности — в теле через пустую строку.
`!` после scope (или футер `BREAKING CHANGE:`) — ломающее изменение (формат журнала, правил, CLI скрипта).

| Тип | Когда |
|---|---|
| `feat` | новый скилл, команда, возможность |
| `fix` | исправление ошибки в коде/правилах |
| `refactor` | переделка без изменения поведения |
| `perf` | ускорение |
| `docs` | только CLAUDE.md / SKILL.md / README |
| `test` | тесты |
| `build` / `ci` | зависимости, окружение (venv, requirements) / автоматизация |
| `chore` | служебное: .gitignore, хуки, настройки |
| `revert` | откат коммита |
| `data` | результат работы скиллов: журналы `journal/`, выученные `rules/`, отчёты `reports/` |

Scope — проект или скилл: `hub` (корень), `fb` (freedom-broker), `zm` (zen-money-accounting), либо имя скилла —
`fb-portfolio`, `fb-invest`, `fb-advisor`, `zm-import`, `zm-freedom-rate`; `hooks` для `.githooks`. Например:
`data(zm): импорт kaspi и freedom за 02.10–02.11`.

**Без AI-атрибуции:** никаких `Co-Authored-By: Claude …` и «Generated with Claude Code» — ни в коммитах, ни в PR.
Claude Code настроен через `.claude/settings.json` (`attribution`), формат и атрибуцию проверяет `.githooks/commit-msg`.

## Настройка после клонирования

```bash
git config core.hooksPath .githooks
```
