# my-finance-harness

Хаб личных финансов: отчёты, анализ и управление через Claude по готовым скиллам.
Общение, документация и сообщения коммитов — на русском.

## Проекты

| Папка | Назначение |
|---|---|
| `freedom-broker/` | Брокерский счёт Freedom Broker: портфель, правила, наставники (скиллы `fb-portfolio`, `fb-invest`, только чтение) |
| `zen-money-accounting/` | Учёт повседневных доходов/расходов: разбор банковских выписок → операции в Дзен-мани через коннектор |

У каждого проекта свой `CLAUDE.md` — читай его перед работой в проекте.

## Скиллы

Исходники скиллов лежат в `<проект>/skills/<скилл>/`. В `~/.claude/skills/` — только симлинки на них:

```bash
ln -sfn "$PWD/<проект>/skills/<скилл>" ~/.claude/skills/<скилл>
```

Префиксы: `fb-*` — freedom-broker, `zm-*` — zen-money-accounting.

## Жёсткие правила

1. **Исходные документы не хранятся.** PDF/XLSX/CSV-выписки кладутся только во временный `inbox/`, после обработки удаляются. В git их нет (`.gitignore` + `.githooks/pre-commit`).
2. **Хранится только история решений** — журналы `journal/*.jsonl` (только дописывать) и выученные правила `rules/`.
3. **Никаких персональных идентификаторов**: номера карт и счетов — маской `*1234`, ИИН, логины, API-ключи, токены — никогда.
4. Репозиторий — только локальный или приватный.

## Настройка после клонирования

```bash
git config core.hooksPath .githooks
```
