# zen-money-accounting

Целевой сценарий: пользователь присылает PDF-выписку (Freedom, Kaspi и т.д.) → операции разбираются,
сверяются с уже существующими в Дзен-мани, категоризируются и заносятся через коннектор Дзен-мани.
Каждое решение логируется, чтобы со временем учёт шёл всё более автоматически.

## Коннектор Дзен-мани

Официальный MCP `https://api.zenmoney.app/mcp` (OAuth), подключён в корневом `.mcp.json` как `zenmoney`.
Документация: https://github.com/zenmoney/ZenPlugins/wiki/Zenmoney-MCP. Банки он не синхронизирует и деньги не двигает.

- Чтение: `get_user`, `list_accounts`, `get_account_balances`, `list_categories`, `list_transactions`
  (фильтры: период, счёт, категория, тег, контрагент, комментарий, сумма), `list_scheduled_transactions`,
  `get_monthly_report`, `get_instrument_rates`, `search_merchants`, `search_financial_institutions`, `search_help`
- Запись: `upsert_transactions` (операции, переводы, долги), `delete_transactions` (**безвозвратно**),
  `upsert_accounts`, `upsert_categories`, `create_merchant`

`delete_transactions` вызывать только по явной просьбе пользователя, указав конкретные операции.

## Структура

- `inbox/` — временное место для выписок. **Не коммитится. После обработки файл удаляется.**
- `rules/` — выученные правила (коммитятся):
  - `merchants.json` — контрагент/шаблон описания → категория Дзен-мани (+ откуда правило взялось)
  - `accounts.json` — банк + маска карты/счёта → счёт в Дзен-мани
- `journal/` — только дописывать (коммитится):
  - `imports.jsonl` — одна строка на обработанную выписку: банк, период, сколько операций найдено/добавлено/пропущено/дублей
  - `decisions.jsonl` — одна строка на решение по операции: что увидели, что решили и почему
- `skills/zm-*` — скиллы проекта (симлинки в `~/.claude/skills/`)

## Формат решения (`decisions.jsonl`)

```json
{"ts": "2026-11-02T19:00:00+05:00", "import_id": "kaspi-2026-10", "bank": "kaspi", "account": "*1234",
 "date": "2026-10-15", "amount": -4500, "currency": "KZT", "description": "Magnum Cash&Carry",
 "action": "added|skipped|duplicate|transfer|asked_user", "category": "Продукты",
 "reason": "rule:merchants.json#magnum | user | guess", "zm_id": "<id операции в Дзен-мани или null>"}
```

## Правила обработки

1. В журналы — только данные операции (дата, сумма, валюта, описание контрагента). Номера карт/счетов — маской `*1234`; ИИН, ФИО третьих лиц из переводов, остатки по счетам — не писать.
2. Перед добавлением — проверка на дубли в Дзен-мани (дата ± 1 день, сумма, счёт).
3. Переводы между своими счетами — как перевод, а не расход+доход.
4. Если правила нет и категория неочевидна — спросить пользователя, ответ сохранить в `rules/merchants.json` с `"source": "user"`.
5. Ничего не писать в Дзен-мани без показа сводки и подтверждения, пока пользователь явно не разрешит автоматический режим.
