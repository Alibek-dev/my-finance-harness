# zm-import — выписка → Дзен-мани

Корень проекта: `zen-money-accounting/` (папка над `skills/`). Перед работой прочитай `zen-money-accounting/CLAUDE.md`.

## Шаги

1. **Выписка → `inbox/`.** Только туда, никуда больше не копировать.
2. **Разбор:**
   ```bash
   cd zen-money-accounting
   .venv/bin/python skills/zm-import/parse_statement.py inbox/<file>.pdf --summary   # банк, счёт, период, сверка
   .venv/bin/python skills/zm-import/parse_statement.py inbox/<file>.pdf             # + операции
   ```
   Если нет `.venv`: `python3 -m venv .venv && .venv/bin/pip install -r skills/zm-import/requirements.txt`.
   Вывод не сохранять в файлы. `checks_ok: false` → стоп, разобраться, почему не сходится (не импортировать).
   `ok: null` у Freedom = в типе есть валютные операции; смотри `implied_rate` — должен быть правдоподобным курсом.
3. **Счёт:** `rules/accounts.json` (`"<bank>:<маска>"` → счёт Дзен-мани). Нет записи — `list_accounts`, спросить, сохранить.
4. **Дедуп:** `list_transactions` за период выписки по этому счёту (длинный период — по месяцам). Совпадение = сумма
   и дата ±1 день (для `pending` — ±3 дня, сумма в валюте операции). Совпало → `duplicate`, не добавлять.
5. **Переводы между своими счетами** — один перевод, а не расход + доход. Известные пары — в `rules/accounts.json → transfers`.
   Перевод уже заведён со стороны другого счёта (другая выписка / синк банка) → `duplicate`.
6. **Категория:** `rules/merchants.json` (регэксп по `details` → категория). Нет правила и неочевидно — спросить;
   ответ записать правилом с `"source": "user"`. Своё предположение помечать `"source": "guess"` и показывать в сводке.
7. **Сводка → подтверждение.** Таблица: дата, сумма, описание, действие, категория/счёт-получатель, причина.
   Отдельно: дубли, переводы, вопросы. Без явного «да» ничего не писать.
8. **Запись:** `upsert_transactions` пачками (≤ 50). Сохранить `zm_id` из ответа.
9. **Журнал** (только дописывать): строка на операцию в `journal/decisions.jsonl`, строка на файл в `journal/imports.jsonl`.
10. **Удалить PDF** из `inbox/`, закоммитить `journal/` и `rules/`.

## Особенности банков

- **Kaspi Gold:** сводка сходится точно по всем типам. Возвраты приходят как `Покупка` с `+` (пара ±одинаковая сумма в один
  день = отмена → обе `skipped`). «Перевод на свой счет» / «Поступление со своего счета» — движения внутри Kaspi
  (Депозит, Red, Кредит). «На карту Freedom Finance Bank*7488» — перевод на Freedom.
- **Freedom Super Card:** мультивалютная карта (KZT, USD…). `Сумма в обработке` = ещё не проведена (`status: pending`),
  в следующей выписке станет `Покупка`. «Прием вклада» / «Перевод вклада по Договору №*XXXX» — движения с депозитами.
  `FRPAY FREEDOM BROKER` — пополнение брокерского счёта. Строки, порванные границей страницы, парсер склеивает.

## Нельзя

Хранить PDF и выгрузки; писать в файлы IBAN, ИИН, ФИО, остатки; вызывать `delete_transactions` без явной просьбы
по конкретным операциям.
